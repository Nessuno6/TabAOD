# Changelog

## v0.9

- New settings screen: a live preview of the AOD next to grouped settings.
- When to show: Auto, Always, As scheduled, For new notifications.
- Now bar: music, timers, stopwatches, calls, navigation and progress at the bottom of the AOD.
- Lock screen clock style, matching One UI's lock screen clock.
- Lock screen widgets are copied from what the lock screen actually shows, at the same
  positions (previously stale widgets could be copied and some dropped).
- Fingerprint icon over the under-display sensor.
- Smaller burn-in shift (at most about 0.5% of the screen), reset when the screen wakes, so
  nothing jumps when the lock screen appears.
- Automatic updates for the app and the root module from GitHub releases.
